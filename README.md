# MacEwan Vertical Gardens: demo store

A one-page proof-of-concept storefront for **MacEwan Vertical Gardens**, Team I's venture for BUSN 201 at MacEwan University.

It shows what buying a tower would feel like: mission statement, the 7-tier hydroponic tower at $505 CAD, what's in the box, how it works, quarterly workshops in Edmonton, the team, an FAQ, a working cart (GST 5%, FedEx shipping included) and a demo checkout with an order confirmation.

**This is a demo.** Nothing is sold, no payment is taken and no personal details are collected. The cart is saved only in the visitor's own browser.

## Files
- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `images/` – product and lifestyle photos (supplier product photos; close-up photos from Unsplash)
